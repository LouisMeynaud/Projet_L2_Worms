# PROJECTILES

## Ajouter un nouveau projectile :

> **Important :** Le nom du fichier image doit correspondre **exactement** au nom de la classe Java du projectile.
> De plus, la classe doit impérativement suivre la convention : `NomProjectile.java`.

- Une fois l'implémentation du projectile terminée :
  - L'image du projectile est à ajouter dans le dossier **_ressources/sprites/projectile_**
  - Il faut ajouter le nom de la classe dans l'enum `Projectile` de la classe abstraite `Projectile` afin que les textures chargent correctement.
